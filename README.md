# BioMedTech Solutions - Landing Page

A polished marketing site for a fictional biomedical-technology company. It presents AI-assisted diagnostic and treatment devices, the technology behind them, customer references and a demo-request form.

![BioMedTech landing page](docs/screenshot.png)

**[Live demo](https://vaas125.github.io/biomedtech-landing-page/)**

## Highlights

- **Hero section** with a gradient headline, certification badge and clear calls to action
- **Product, technology and references sections** with hover and scroll-reveal animations
- **Demo-request form** with a styled, validated layout
- Healthcare-style visual identity: teal gradient palette, rounded cards, subtle depth
- **Fully responsive**, single file, no build step or dependencies

## Tech stack

HTML5, CSS3 (custom properties, Grid, Flexbox, keyframe animations), vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Notes

This is a design and front-end exercise. The company, products and certifications are fictional, and the form does not send data anywhere. The page content is in Turkish.
